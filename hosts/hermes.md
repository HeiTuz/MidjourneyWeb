# Hermes host

Use the browser capability actually enabled in the current Hermes session and the user's chosen authenticated browser. Codex's in-app browser and `cua_repl` examples in the shared references do not establish Hermes tools. Follow the enabled capability's own navigation, snapshot, upload, download and waiting contracts.

Installation supplies a skill under the image-generation category, not an API client, browser service or authentication state. When a required browser operation is unavailable, report the precise missing capability and do only the independently possible work. Do not change the running Hermes configuration or restart its service as part of skill use. Browser execution on this host is not yet live-tested by this project.
