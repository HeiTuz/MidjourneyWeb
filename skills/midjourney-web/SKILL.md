# Midjourney Web

미드저니 사이트의 실제 화면을 조작해 요청한 결과를 만든다. [호스트 안내](references/host.md)를 먼저 읽는다. Codex의 기본 실행 환경은 **인앱 브라우저**이며, 다른 호스트는 현재 제공된 브라우저 도구를 사용한다. Google 로그인 세션을 재사용하고 사용자의 브라우저 선택을 따른다.

## 시작

1. 현재 요청이 탐색, 프롬프트 준비, 생성, 편집, 정리 중 무엇인지 구분한다. 스킬 설치·조사는 생성이나 계정 변경 승인이 아니다. 요청된 생성 범위와 이미 승인된 GPU 사용량 안에서 실행하며 같은 승인에 재확인을 요구하지 않는다.
2. 현재 브라우저 도구의 진입 규약을 읽고 기존 미드저니 탭을 재사용한다. [브라우저 실행](references/browser.md)을 읽는다.
3. 입력 원본, 대상 작업, 버전, 개인화, 레퍼런스 역할, 출력 크기, 생성 수량과 저장 위치를 현재 화면에서 확인한다. 작업에 무관한 기본 설정을 바꾸지 않는다. 이전 세션의 번호·좌표·프로필 코드를 그대로 재사용하지 않는다.
4. 해당 기능의 참고 파일만 읽는다. 버전이나 지원 여부가 다르면 [공식 문서 목록](references/sources.md)에서 최신 내용을 확인한다.

## 결과를 식별하는 기준

- 제출 전에 기존 작업 링크와 입력 상태를 파악한다. 제출 후 **새 작업 ID와 URL**을 확보하고 프롬프트·참조·작업 종류를 대조한다. 이미 있던 이미지나 페이지 전체 버튼 수로 완료를 판정하지 않는다.
- 한 생성 작업과 결과 이미지 수는 다르다. 사용자가 원하는 납품 수량과 사이트가 만드는 배치 수량을 구분한다. 추가 변형·HD·스타일 미리보기·영상은 새 GPU 작업이다.
- 결과 불명 상태에서는 Create에서 이번 제출의 존재 여부부터 확인한다. 완료됐는지 모른다는 이유로 같은 프롬프트를 다시 제출하지 않는다.
- 비교는 동일 작업 안의 후보를 실제로 열어 수행한다. 사용자 원본과 요청된 보존 요소를 기준으로 평가하고, 선택된 후보는 작업 ID와 이미지 인덱스로 기록한다. 반복 요청에 상한이 없으면 무한 생성하지 말고 우선 한 배치 결과를 보여준다.
- 저장 요청의 완료는 원본 파일의 존재·형식·크기 확인까지다. 화면 캡처는 검토 증거이며 원본 납품물이 아니다.

## 전달

선택 결과, 작업 링크, 실제 저장 경로와 요청한 수정의 반영 여부를 간결하게 전달한다. 준비·제출·생성 완료·다운로드 완료를 구분한다. 계정·플랜 제한이나 미검증 기능은 구체적으로 밝힌다. 작업용 탭은 다음 작업을 이어갈 필요가 있을 때 현재 도구 규약에 따라 유지한다.
