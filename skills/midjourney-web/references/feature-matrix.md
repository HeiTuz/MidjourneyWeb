# Feature evidence matrix

Reviewed 2026-09-12. **Live UI** means navigation/control inspection only. **Live file** means bytes were saved and decoded. **Documentation-only** means execution is untested. **Plan-gated** describes documented eligibility, not a diagnosis of the tested account. **Retired** is distinct from a feature still available on older models. No row implies the entire site passed end-to-end testing. Earlier observations are identified in [evidence.md](evidence.md).
